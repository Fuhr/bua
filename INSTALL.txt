Bua — install guide
====================

Bua is a tiny lotus that lives in your menu bar and breathes with your
Claude Code session. It's a personal app shared by a friend, so it isn't
signed by Apple — macOS will warn you once. Here's how to get past it.

1. Drag  Bua.app  into your Applications folder.

2. Double-click Bua. macOS will say it "can't verify Bua is free of
   malware" and refuse to open it. That's expected — click Done.

3. Open  System Settings → Privacy & Security. Scroll to the Security
   section: you'll see "Bua was blocked…". Click  Open Anyway, then
   confirm with Touch ID or your password.

4. Bua opens — look for the little lotus in your menu bar (top-right).
   You only do this once.

Prefer the terminal? Skip steps 2–3 and paste this instead:

   xattr -dr com.apple.quarantine /Applications/Bua.app
   open /Applications/Bua.app

What Bua needs to show data
---------------------------
• An Apple Silicon Mac on macOS 15 (Sequoia) or newer.
• Claude Code installed and logged in — Bua reads your session usage.
  No Claude Code yet? The lotus simply rests, calmly.

Press ⌃⌥B anywhere to show/hide the panel. Right-click the lotus for
options (pin, demo, launch at login, edit quotes, quit).

Privacy
-------
Bua reads your Claude Code token read-only and sends it to exactly one
place: api.anthropic.com/api/oauth/usage — the same endpoint Claude
Code's own /usage screen uses. It never sees your conversations, and
never stores or refreshes anything. If anything fails, the lotus rests.
